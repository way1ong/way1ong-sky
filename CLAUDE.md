# way1ong-sky — правила для Claude Code

Безкоштовна програма про космос від way1ong **без реклами, без стеження, без акаунтів**. Перший режим — політ Сонячною системою в 3D: Сонце, планети й Місяць там, де вони справді є сьогодні. Другий — «Небо звідси»: карта неба для вибраного міста. Аудиторія — насамперед жителі Європи, дорослі й старші. Програма — водночас приклад робіт для сайту way1ong.eu (розділ «Космос»).

- Опис програми — `docs/SPEC.md`.
- Рішення з датами — `docs/DECISIONS.md`. Кожне нове рішення Дмитра — туди, у тому ж коміті.
- Що зроблено й що далі — `docs/STATUS.md` (оновлювати в кінці кожного кроку).
- Джерела даних і ліцензії — `docs/SOURCES.md`. Нове джерело — спершу туди, з адресою, ліцензією й датою, коли її прочитано.

## Порядок роботи
- Спершу план, потім дії: показати план кроків, чекати погодження. Без дозволу нічого не починати, особливо на старті сесії.
- Реальність розійшлась із планом — зупинитись і повернутись з поправкою.
- До погоджених рішень не повертатись; застереження — один раз. Нову проблему називати завжди.
- Спілкування з Дмитром українською, коротко. Код, ідентифікатори, коміти — англійською.
- Гілка сесії `ccr-*` → pull request у `main`. Зливає Дмитро.
- Перед комітом — `npm run verify` (типи, тести, збірка) має бути зелено; зміни екрана — ще й перевірка в браузері на телефоні й ПК. Комітити конкретні файли, не `git add -A`.

## Непорушні правила
1. **Без реклами, покупок і стеження.** Жодних рекламних мереж, аналітики, лічильників. Програма нічого не надсилає в мережу; налаштування — лише на пристрої.
2. **Без зовнішніх запитів.** Шрифти, картинки, дані — з самої програми; без CDN. Посилання на джерела в «Про програму» — звичайні посилання, не запити.
3. **Жодних чисел і фактів з пам'яті** — ні в коді, ні в текстах, ні у відповіді. Про Сонячну систему — лише з джерела з адресою й датою (`src/data/`, `docs/SOURCES.md`). Числа самої програми (масштаби, камера) — рішення в `src/config.ts`.
4. **Ліцензія кожного джерела — прочитана на його власній сторінці**, а не з переказу. Дані «лише для некомерційного використання» не беремо: сайт продає послуги. Підпис, якого вимагає ліцензія, — у «Про програму».
5. **Чесно про те, що є оздобою.** Якщо щось намальовано не за даними (наприклад, зоряне тло) — так і сказано в «Про програму».
6. **Логіка окремо від екрана.** Положення, масштаби, політ камери — чисті модулі TypeScript без DOM і без three.js (`src/core/`), з тестами проти джерел.
7. **Тексти — лише в словниках** `src/i18n/<мова>.json` з однаковими ключами (EN, HU, UK). Угорською — на «Ön».
8. **Зручно старшим і всім.** Цілі дотику ≥ 44 px, без горизонтальної прокрутки сторінки, усе досяжне з клавіатури (список тіл — кнопки), повага до «зменшити рух» у системі.
9. **Окремий файл на кожен модуль** одразу при створенні. Кольори екрана — лише змінні з `src/styles/tokens.css`.
10. **Секрети** — лише в налаштуваннях Cloudflare; у репозиторії їх немає.

## Стек (змінювати лише за погодженням)
- TypeScript (strict) без UI-фреймворку, збірка Vite; тести — Vitest; перевірка в браузері — Playwright (у хмарній сесії вже є; для WebGL запускати Chromium з `--use-angle=swiftshader --enable-unsafe-swiftshader`).
- 3D — three.js; астрономія — astronomy-engine. Версії закріплено в `package.json`.
- Хостинг (далі) — Cloudflare Workers зі статичними файлами, адреса `sky.way1ong.eu` (рішення 24.11); деплой — злиття в `main`; вручну `wrangler deploy` не запускати.

## Структура
```
src/config.ts          усі числа самої програми (масштаби, камера)
src/data/bodies.json, facts.json  числа про Сонячну систему з довідників NASA — з адресою й датою
src/data/cities.json   міста для карти неба (Вікідані) — робить scripts/stars/cities.mjs
src/data/stars.json, constellations.json  зорі (Вікідані, CC0) і які з них з'єднано в сузір'я (d3-celestial, BSD-3) — робить scripts/stars/build.mjs, руками не правити
src/data/descriptions.json  сторінки NASA Science, за якими написано описи тіл; речення NASA під кожним описом — docs/DESCRIPTIONS.md
src/core/              логіка без DOM: тіла, положення (astronomy-engine), масштаби, політ камери й вільний політ, годинник програми, тіні й затемнення, місця посадок на Місяці; небо з місця на Землі: sky.ts (де світило над обрієм), stars.ts, dome.ts (купол на екрані), tonight.ts («сьогодні на небі»), places.ts (міста); поруч тести
src/ui/                екран: сцена three.js, керування, список тіл, підписи, меню; небо — sky-view.ts (малює на полотні), вікна place-dialog.ts і tonight-dialog.ts
src/i18n/              словники en/hu/uk.json; i18n.test.ts їх звіряє
src/styles/            tokens.css (кольори), app.css; claude-page.css — лише для тестової сторінки
src/textures/          мапи тіл і тло (Solar System Scope, CC BY 4.0) — docs/SOURCES.md
src/photos/            фото тіл для карток (NASA); запис і автор кожного — src/data/photos.json, підписи й джерела — docs/PHOTOS.md
src/photos/sites/      фото з місць посадок «Аполлонів»; src/data/sites.json — координати, дати, екіпажі, числа місій зі сторінок NASA
scripts/claude-page.mjs  програма одним файлом для тестової сторінки claude.ai
scripts/stars/         збирання файлу зір із сирих відповідей Вікіданих: build.mjs, exclude.json (відкинуті записи з причинами), лінії d3-celestial з його ліцензією
docs/                  опис, рішення, стан, джерела й ліцензії; docs/research/ — розвідка джерел для карти неба (звіт і сирі відповіді Вікіданих)
```

## Команди
- `npm run dev` — локальний перегляд.
- `npm run verify` — типи, тести, збірка в `dist/`.
- `npm run preview` — переглянути зібране.
- `npm run build:claude` — програма одним файлом `dist/claude/sky.html` для тестової сторінки.

## Тестова сторінка (claude.ai)
Адреса — у `docs/STATUS.md`. Після кожної зміни програми: `npm run build:claude`, перевірити, опублікувати файл на ту саму адресу (інструмент `Artifact`, з іншої розмови — з `url`).
