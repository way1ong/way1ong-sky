# way1ong-sky

A free, ad-free app about space by way1ong, in two modes: a 3D flight through the Solar System — the Sun, the planets and the Moon where they really are today — and a map of the sky over a chosen city. No tracking, no account; it can be installed and works without internet.

- Rules for work in this repository — `CLAUDE.md`.
- What the app is — `docs/SPEC.md`; what is done and what is next — `docs/STATUS.md`; decisions — `docs/DECISIONS.md`.
- Sources and licences — `docs/SOURCES.md`, `docs/PHOTOS.md`, `docs/DESCRIPTIONS.md`, `docs/research/`.
- How it gets on the web (Cloudflare) — `docs/cloudflare.md`.

Commands: `npm run dev`, `npm run verify` (types, tests, build), `npm run audit` (the built app in a browser), `npm run check:live` (the live address against the build).
